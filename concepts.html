Key Concepts

These six ideas are the building blocks for understanding how HTTP and HTTPS work.

1. Client and Server

The client (usually a web browser) asks for content. The server is the computer that stores the website and sends that content back.

2. Request and Response

Every HTTP exchange is a pair: the client sends a request, and the server answers with a response containing a status code, headers, and usually a body.

3. HTTP Methods

Methods tell the server what action to take. GET reads data, POST sends new data, PUT updates it, and DELETE removes it.

4. Status Codes

Three-digit numbers that report the result. 200 means OK, 301 means moved, 404 means not found, and 500 means a server error.

5. Headers

Extra information sent with a request or response, such as the content type, the browser being used, or cookies.

6. Statelessness

HTTP does not remember earlier requests on its own. Websites use cookies and sessions to remember things like who is logged in.
