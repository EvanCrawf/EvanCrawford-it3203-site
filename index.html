HTTP & HTTPS: How Browsers and Servers Talk

Abstract

HTTP (Hypertext Transfer Protocol) is the set of rules that web browsers and servers use to request and deliver pages, images, and other content. This site traces how HTTP grew from a simple protocol at CERN into the fast, encrypted HTTPS that almost every website uses today. It covers each major version of HTTP, what problem each version solved, and how TLS encryption keeps information private and safe.

Key Terms

  • HTTP – Hypertext Transfer Protocol
  • HTTPS – HTTP secured with encryption
  • TLS – Transport Layer Security
  • Request / Response
  • Status Code
  • QUIC – the transport used by HTTP/3
